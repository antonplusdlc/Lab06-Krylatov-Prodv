# ПР6. Ответы на контрольные вопросы
1. void ничего не возвращает
2. вся остальная часть метода не выполняется, циклы завершаются и метод заканчивает свое выполнение
3. если у них разное количество или разные типы параметров компилятор сам поймёт, какой из них вызвать
4. компилятор не сможет понять, какой метод вызвать, если параметры совпадают, а различается только то, что метод возвращает
5. например, добавление записи в бд
6. это означает, что один метод использует результат или выполняет действия другого метода
